# Code of Conduct

Leeds Harvester aims to be a friendly project for people of every background and experience level.

## Expected behaviour

- Be respectful and assume good intent.
- Give constructive, specific feedback on code and ideas, not on people.
- Help newcomers find their way.
- Accept maintainer decisions gracefully, and discuss disagreements openly and politely.

## Unacceptable behaviour

- Harassment, insults, discriminatory jokes or language, and personal attacks.
- Publishing other people's private information without permission.
- Sustained disruption of discussions.
- Using the project to collect personal data in violation of law or a site's terms.

## Enforcement

Report problems privately to the maintainer through the contact listed on the [maintainer's GitHub profile](https://github.com/KritishX). Reports are handled confidentially. Maintainers may remove comments, reject contributions, or temporarily or permanently ban participants who break this code.

This code applies in all project spaces: issues, pull requests, discussions, and anywhere someone represents the project.
